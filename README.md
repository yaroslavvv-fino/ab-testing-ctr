# A/B-тестирование: анализ агрегированных данных по кликам и просмотрам

## Данные

Датасет: A/B Test Results Aggregated <https://www.kaggle.com/datasets/sergylog/ab-test-aggregated-data/data>

Содержимое: 120 000 записей (по одной на каждого пользователя)

Поля:

```user_id``` – идентификатор пользователя

```group``` – группа эксперимента (control или test)

```views``` – количество показов страницы

```clicks``` – количество кликов

Данные уже агрегированы до уровня пользователя

## Методология

Предварительный анализ:

- Проверка на пропуски и дубликаты

- Визуализация распределений показов, кликов и пользовательского CTR

### Метрики:

- Основная метрика успеха – общий CTR = общие клики / общие показы

- Дополнительно анализируется средний пользовательский CTR для сравнения распределений

### Статистические тесты:

- Z-тест для пропорций (```statsmodels.stats.proportion```) – сравнение общего CTR

- U-тест Манна-Уитни (```scipy.stats.mannwhitneyu```) – непараметрическое сравнение распределений пользовательского CTR

- T-тест (```scipy.stats.ttest_ind```) – приведён для сравнения, но не является основным из-за скошенности распределения

### Дополнительный анализ:

- Доверительные интервалы (95%) для CTR и разницы CTR

- Размер эффекта (Cohen's h)

## Результаты

- Общий CTR в тестовой группе составил 3.85% против 3.47% в контрольной (прирост +0.38 %, +11% относительного роста).

- Z-тест: p-value < 0.0001 (значимо)

- U-тест: p-value < 0.0001 (значимо)

- 95% доверительный интервал для разницы CTR: [0.29 %, 0.48 %]

- Размер эффекта (Cohen's h) = 0.02 – очень малый эффект

**Вывод:** Новая версия статистически значимо повышает кликабельность, однако абсолютный прирост невелик. Для принятия бизнес-решения рекомендуется оценить влияние на конечную конверсию и затраты на внедрение.
